# WashEase

Web-Based Laundry Service Management System with
Zone-Time-Load Prioritization Algorithm (ZTLPA)-Driven Delivery Scheduling.

## Architecture

- Backend: Laravel
- Frontend: Next.js / React
- Database: MySQL
- Real-time: Laravel Reverb
- Version Control: Git / GitHub

## Main Modules

1. Customer Management
2. Order Management
3. ZTLPA Delivery Scheduling
4. Rider Assignment
5. Customer Booking and Order Tracking
6. Payment Tracking and Reports
